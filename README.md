# Conformal Risk Sharing

Code for the paper **Conformal Risk Sharing: Certified Cost Allocation with Participation Guarantees** (UAI 2026).


## Repository structure

```
csan.py                    Core library: policy class, conformal certificates,
                           train–select–certify backtests, data generation,
                           dataset loaders, diagnostics, and plotting/LaTeX helpers
CRS_global.ipynb           Synthetic experiment, global-uniform pooling
CRS_local.ipynb            Synthetic experiment, local (neighbourhood) pooling
CRS_eobs.ipynb             E-OBS precipitation experiment (Section 5.2)
CRS_energy-coop.ipynb      Energy-cooperative experiment + dependence diagnostics (Section 5.3)
```


### Key governance parameters

| Symbol | Argument | Meaning |
|--------|----------|---------|
| δ      | `delta`  | Target miscoverage (e.g. `0.1` for 90% certificates) |
| η      | `eta`    | Per-agent materiality threshold below which cap increases are ignored |
| ε      | `eps`    | Harm budget as a fraction of the baseline aggregate certified cost |

## Reproducing the paper experiments

**Synthetic (Section 5.1).** Run `CRS_global.ipynb` and `CRS_local.ipynb` end to end. No external data is required; blocks are generated by `make_synth_blocks`.

**E-OBS precipitation (Section 5.2).** Download the E-OBS daily gridded rainfall product (`rr`, 0.25° regular grid) from the Copernicus / ECA&D E-OBS dataset.

**Energy cooperative (Section 5.3).** Obtain the CEL Loureiro electricity-consumption dataset (Monteiro et al., 2024).

> **Note on data.** The E-OBS and CEL Loureiro datasets are **not redistributed in this repository** and are subject to their own licences and terms of use. Please obtain them from the original providers and update the paths above as needed. The synthetic experiments require no external downloads.
